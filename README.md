# como_project4
## Content
Scripts:
- code_examples: code examples and notebooks for NLP and LLM, mainly from Tais
- text_processing functions.py: functions for text processing from IFRC reports
- LLM_functions.py: functions related to the LLM analysis
- plot_functions.py: functions for plotting
- data.py: definitions of absolute path to data and for results
- constants.py: where to define constants e.g. hazard dict.
- prompts.py: definition of prompts to query LLMs
- post_processing_functions.py: function to post-process output from LLMs
Notebooks:
- 1 notebook to scrap data for reports
- 1 notebook to process data from reports
- 1 test notebook for extracting data using LLM
- 1 operational notebook for extracting data from all reports using LLM
- 1 notebook for postprocessing results
- 1 notebook to label reports
- 1 notebook for the accuracy of the data extraction
- notebooks for analysis of results and plotting
